# NBA Game Predictor

Este app usa modelos de IA para prever resultados de jogos da NBA, gerando análises estatísticas e probabilidades de vitória.

## Como funciona

O usuário escolhe os times e o sistema:

- Processa estatísticas atualizadas
- Usa modelo preditivo
- Gera probabilidades de vitória
- Exibe gráficos e análise automática por IA

## Tecnologias usadas

- Streamlit
- Python
- Machine Learning
- APIs de dados esportivos
